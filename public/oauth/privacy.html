MVCIinfo（以下「運営者」）が提供する MVCI配信自動更新（以下「本サービス」）における情報の取扱いを説明します。本サービスは YouTube API サービスを利用します。

取得・利用する情報

本サービスは YouTube チャンネルの公開メタデータ（動画 ID、タイトル、公開日時、配信状態など）を取得し、公開ページ、RSS、JSON に掲載します。動画は YouTube の埋め込みプレーヤーで再生されます。運営者は自身の機能実行のため、youtube.force-ssl 権限で公開メタデータと自身のプレイリストを読み取り、動画の追加や並び順の更新を行います。

Google OAuth を利用するのは運営者だけです。閲覧者に Google ログインを求めず、閲覧者の Google 認証情報は取得しません。情報を販売せず、広告や AI モデルの学習にも利用しません。

保存・公開

OAuth の更新用認証情報は運営者のローカル JSON ファイルと GitHub Secrets で管理し、GitHub Actions から利用します。公開メタデータは GitHub Pages のページやフィードに掲載され、次回のビルドで現在の出力に置き換わります。GitHub Actions のログやアーティファクトは GitHub の保持設定に従います。Cloudflare Worker を利用する場合も、Google OAuth 認証情報は扱いません。

第三者サービス・削除

GitHub Pages／Actions によるホスティング・自動処理や YouTube の埋め込みにより、IP アドレスや Cookie などが各事業者に送信・保存される場合があります。取扱いは各社の説明をご確認ください。

Google アカウントのアカウントへのアクセス権から、本サービスへの許可を取り消せます。公開データの削除依頼は GitHub Issuesへお寄せください。パスワードやトークンなどの秘密情報は記載しないでください。
