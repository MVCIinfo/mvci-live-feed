MVCIinfo（以下「運営者」）は、MVCI配信自動更新（以下「本サービス」）における情報の取扱いについて、以下のとおり定めます。本サービスは、YouTube API サービスを利用します。

1. 本サービスが扱う情報

本サービスは、対象となる YouTube チャンネルの公開情報（動画 ID、タイトル、公開日、ライブ配信の状態など）を取得し、公開ページ、RSS、JSON フィードに表示します。動画の再生には YouTube の埋め込みプレーヤーを使用します。

本サービスを閲覧する方に Google ログインを求めず、閲覧者の Google OAuth 認証情報を取得しません。YouTube 埋め込みやウェブサイトのホスティングにより、利用者の IP アドレスなどが YouTube やホスティング事業者に送信される場合があります。各事業者の取扱いは、それぞれのプライバシー情報をご確認ください。

2. Google OAuth と利用目的

運営者は、運営者自身のプレイリストを管理する機能のために Google OAuth を使用します。要求する youtube.force-ssl 権限は YouTube アカウントのデータを広く読み取り・管理できる権限です。本サービスでは公開メタデータの取得に加え、運営者のプレイリストを読み取り、動画を追加し、並び順を更新します。対象プレイリストは PLIA2oKVHJxPs です。閲覧者は Google アカウントでログインする必要はありません。

OAuth データは上記機能の実行にのみ使用します。第三者への販売、広告目的での利用、AI モデルの学習への利用は行いません。

3. 保存と公開

取得した公開メタデータは、ビルド時に公開フィードやページへ出力され、次回の更新で置き換えられます。運営者は OAuth の更新用認証情報をローカルの JSON ファイルで管理し、GitHub リポジトリの Secrets に登録して GitHub Actions から利用します。アクセストークンは実行中のメモリ上で扱います。認証情報を公開ページや公開リポジトリに掲載することは意図していません。

GitHub Actions はフィードの生成と GitHub Pages への公開に使います。ジョブログやアーティファクトの保存期間・バックアップは GitHub の設定とサービス仕様に従います。Cloudflare Worker は、導入されている場合にチャンネル設定や公開メタデータ、WebSub 通知、GitHub Actions 起動用トークンを扱う構成として想定されていますが、Google OAuth 認証情報は扱いません。本ポリシーは Worker の稼働状況を示すものではありません。

4. 保存期間と削除

公開メタデータはフィードの更新時に現在の出力へ反映されます。運営者は設定および公開ファイルを編集・削除できますが、GitHub のジョブログ、アーティファクト、バックアップに残る情報は、それぞれの保存設定と保持期間に従います。個別の保存期限を一律には定めていません。

Google アカウントの アカウントへのアクセス権から本サービスへの許可を取り消せます。許可の取消しだけでは、すでに公開されたメタデータは自動削除されません。削除を希望する場合は下記窓口へご連絡ください。確認のため、運営者が必要に応じて本サービスを許可した Google アカウントと同じアカウントからの連絡をお願いすることがあります。パスワード、トークン、秘密情報は送らないでください。

5. 第三者サービスと関連規約

  • YouTube の API および埋め込み機能を利用します。YouTube 利用規約と Google プライバシーポリシーをご確認ください。
  • ページとフィードのホスティング、および自動ビルドに GitHub Pages と GitHub Actions を利用します。GitHub プライバシーに関する声明をご確認ください。

6. お問い合わせ

本ポリシーや公開情報の削除に関する連絡先は MVCIinfo/mvci-live-feed の GitHub Issuesです。連絡時に、パスワードや OAuth トークンなどの秘密情報を記載しないでください。
